# 🎵 Spotify Music Analytics Dashboard

## 📌 Project Overview

This project is a **Spotify Music Analytics Dashboard** created using **Microsoft Excel**.

The main objective of this project is to analyze Spotify music data and extract useful insights related to songs, artists, streams, energy, danceability, acousticness, and other music-related attributes.

I used Excel for **data analysis, Pivot Tables, Pivot Charts, filtering, calculations, and dashboard creation** to convert raw Spotify data into an interactive and easy-to-understand dashboard.

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Filters / Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Dashboard Visualization

## 🧹 Data Analysis Process

The project was completed completely in **Microsoft Excel**.

### Step 1: Data Preparation
- Imported the Spotify dataset into Excel.
- Reviewed the available columns and data types.
- Checked the data for consistency and missing values.

### Step 2: Data Cleaning
- Organized the dataset.
- Checked duplicate and inconsistent records.
- Prepared the data for analysis.

### Step 3: Data Analysis
- Created Pivot Tables.
- Calculated KPIs.
- Grouped data by release year, artist, and track.
- Analyzed different music attributes.

### Step 4: Data Visualization
- Created Pivot Charts.
- Used bar charts and line charts for comparisons and trends.
- Added slicers/filters for interactive analysis.

### Step 5: Dashboard Creation
- Combined KPIs, charts, and filters into a single dashboard.
- Designed the dashboard to make important insights easy to understand.
